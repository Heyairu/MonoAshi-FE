MonoAshi とは？

MonoAshi は物語を書く人のための、Flutter 製のオープンソース執筆ツールです。本文、章、構成案、登場人物、世界設定、アイテム、タイムラインをひとつの作業画面にまとめられます。

原稿はどこに保存されますか？

作品は指定したローカルの場所に .mnproj ファイルとして保存されます。自動保存は既存ファイルを更新し、自動バックアップは設定したフォルダーに別途保存します。どちらも設定画面で調整できます。外部 AI や共同編集を有効にする前に、接続方法とアクセス対象のデータを確認してください。

どのエクスポート形式に対応していますか？

本文は TXT または Markdown、設定資料は閲覧用 Markdown、プロジェクトの一部は交換用 XML としてエクスポートできます。単一ファイルか、複数ファイルをまとめた ZIP を選べます。完全なデータを保存するには .mnproj ファイルを保管してください。DOCX と PDF の出力は現在無効です。

AI は必須ですか？

AI の利用は任意です。本文編集と設定管理は単独で使えます。Copilot はご自身の API キーでサービスに接続します。Ask と Plan はビルド時の有効化が必要です。Plan は提案と検証に対応し、Agent は現在利用できません。許可されたローカル MCP ホストは作品を読み取り専用で参照できます。

どの端末に対応していますか？

Flutter プロジェクトには Windows、macOS、Linux、Android、iOS、Web 向けの構成が含まれています。機能、検証状況、配布されるビルドはプラットフォームごとに異なります。詳細は GitHub Releases と利用ガイドを確認してください。

ダウンロードや開発への参加方法は？

まず GitHub Releases で配布ビルドと対応プラットフォームを確認してください。開発者はリポジトリの README を参照してソースから実行できます。バグ報告や改善提案は Issues で受け付けています。
