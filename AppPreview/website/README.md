# 網站用實際介面擷取

這裡的 PNG 原圖由 `dart_edition/tool/capture_website_screenshots_test.dart` 擷取專案實際的 Flutter 工作區。採用獨立的虛構展示作品《星海之間》、M3 Teal 主題、Noto Sans／Noto Sans TC 及原版 Material Icons。

擷取範圍為 Flutter 的應用程式內容，不含作業系統標題列；沒有讀取使用者正在編輯的稿件。維護步驟見 [`docs/WEBSITE.md`](../../docs/WEBSITE.md)。網站實際載入的是由這些原圖壓縮的 `docs/assets/screenshots/*.webp`。
